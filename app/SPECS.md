# Common Scratch Pad

The app for Common Scratch Pad Preparation.

## Overview
Common Scratch(Pad) is a reading group originally started in the East Bay/Oakland Area in 2026.
We met at Clio's, which we didn't know had a no-screens policy, and immediately loved the conversational vibe that forced: riffing, creative remembering, etc.

## The App
The app is simple:
* A common space to render a pdf alongside per-person-tracked annotations/drawings on *and around* the paper pages.
* Add a BIG "COMMON WHITEBOARD" at the end that is an infinite canvas that lets people write things out.
* This will be hosted on github pages, with simple authentications for broad public access.
